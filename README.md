# Devops
Notes on Devops 


DevOps is a combination of Development (Dev) and Operations (Ops). It is a way of working that helps software development teams build, test, deploy, and maintain applications faster and more reliably

1. Git and GitHub
Version control and collaboration
2. Linux and Bash
Operating systems, commands and scripting
3. Maven
Build and manage Java projects
4. Jenkins / GitHub Actions
Automate CI/CD pipelines
5. Docker
Package applications into containers
6. AWS
Run applications in the cloud
7. Kubernetes
Orchestrate containers at scale
8. Terraform
Create infrastructure using code
9. Prometheus / Grafana

Monitor metrics and visualize system health


devopa life cycle 

The DevOps life cycle is the continuous process of planning, developing, building, testing, releasing, deploying, operating, and monitoring a software application.

The DevOps Lifecycle is a continuous process used to develop, test, release, deploy, operate, and improve software applications.

It connects software development with IT operations so teams can deliver software faster, more reliably, and with automation.


Stage	What you do
Plan	Create a Jira task to add an employee API.
Code	Write the controller, service, and DAO; push code to GitHub.
Build	Run mvn clean package to generate a JAR file.
Test	Run JUnit tests and validate the REST API.
Release	Approve and version the application artifact.
Deploy	Run the application on an Ubuntu server or AWS EC2.
Operate	Manage the application process, configuration, and availability.
Monitor	Check logs, errors, CPU, memory, and response times.


Where do CI and CD fit?
- Continuous Integration (CI): Mainly automates code integration, building, and testing.
- Continuous Delivery (CD): Keeps tested software ready for release, often with manual production approval.
- Continuous Deployment: Automatically deploys qualifying changes to production without a manual release approval.
- Continuous Monitoring: Tracks application health and provides feedback throughout operation.
